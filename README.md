# Hasburak Kuyumculuk

Premium kuyumculuk web sitesi. Lacivert + altın tema, animasyonlu logo ve neon altın parıltı efektleri ile çok sayfalı tanıtım sitesi.

## Sayfalar

- `index.html` — Ana Sayfa
- `biz-kimiz.html` — Hakkımızda
- `urunler.html` — Ürün koleksiyonu (40+ kategori)
- `iletisim.html` — İletişim & harita

## Geliştirme

Statik HTML/CSS/JS — herhangi bir build adımı yok.

```bash
npx http-server . -p 3000
```

Sonra `http://localhost:3000` adresinden açın.
